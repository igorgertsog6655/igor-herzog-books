# Igor Herzog Story Worlds

Двуязычный сайт детских книг Игоря Герцога и услуги создания персональной книги.

## Разделы

- каталог книг с фильтрами по возрасту;
- переход к официальным изданиям на ЛитРес и Amazon;
- заказ персональной истории;
- форма связи с прикреплением файлов;
- русская и английская версии.

Сайт автоматически публикуется в GitHub Pages после изменений в ветке `main`.
